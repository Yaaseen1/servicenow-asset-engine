# AALE: Automated Asset Lifecycle Engine (source export)

This repository is the ServiceNow Source Control export of **AALE**, a scoped ServiceNow application that automates IT asset lifecycle decisions (ITAM + ITOM + ITSM).

📖 **Full write-up, process diagram and demo:** [AALE README](https://github.com/Yaaseen1/ServiceNow-Projects/tree/main/Automated-Asset-Lifecycle-Engine-%28AALE%29)

The application files are in the generated folder in this repository. To explore them, import the repository into a ServiceNow developer instance from Studio (Source Control > Import from Source Control).
